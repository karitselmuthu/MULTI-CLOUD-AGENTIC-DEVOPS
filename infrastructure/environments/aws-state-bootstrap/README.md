# AWS state bucket bootstrap

This CloudFormation template prepares the S3 bucket required by the AWS Terraform sandbox root. It is **not deployed**. It names the bucket from the AWS account ID and Region, enables versioning, server-side encryption, block public access, bucket-owner enforced ownership, and a deny for non-TLS requests. The bucket is retained if the stack is deleted. These choices follow the [CloudFormation S3 bucket reference](https://docs.aws.amazon.com/AWSCloudFormation/latest/TemplateReference/aws-resource-s3-bucket.html), [bucket policy reference](https://docs.aws.amazon.com/AWSCloudFormation/latest/TemplateReference/aws-resource-s3-bucketpolicy.html), and [Terraform S3 backend guide](https://developer.hashicorp.com/terraform/language/backend/s3).

In `us-east-1`, the proposed name is `multicloud-agentic-devops-tfstate-<ACCOUNT_ID>-us-east-1`; CloudFormation inserts the account ID at deployment. An authorized **non-root** account administrator must first review the template and available permissions, then create and execute a CloudFormation change set. This repository must never use the account root principal for the bootstrap. The intended stack name is `multicloud-agentic-devops-tfstate`.

No non-root profile is available yet. The account owner should use the AWS console to [configure an IAM Identity Center administrative user](https://docs.aws.amazon.com/singlesignon/latest/userguide/quick-start-default-idc.html), assign access to this account, and then [configure an AWS CLI SSO profile](https://docs.aws.amazon.com/cli/latest/userguide/cli-configure-sso.html). Use the root sign-in only for that account-bootstrap task, then return to the non-root profile. The project needs the new profile name and its verified STS ARN before any live change set is created. A narrower Terraform permission set should be derived from the reviewed plan before routine execution.

After the stack exists, wait for S3 versioning to propagate before the first state write, and verify the bucket's versioning, encryption, public access block, ownership, and policy. Restrict the Terraform runner's S3 permissions to this bucket and its dedicated state key and `.tflock` object. Keep plan files and backend metadata out of Git.
