## Release gate

Run `uv run --locked --extra test python -m pytest -q tests` with PostgreSQL and OPA configured, plus `opa test security/opa infrastructure/policies -v`, `terraform fmt -check -recursive infrastructure`, `terraform validate` in both initialized modules, and `helm lint`/`helm template` for the chart. The [Python workflow](../../.github/workflows/stage-a.yml) and [infrastructure workflow](../../.github/workflows/infrastructure.yml) enforce these local checks on GitHub.

The exact Terraform plan is still the critical integration gap: the current approval digest covers a mock planner proposal, not a saved binary Terraform plan. Terraform `validate` only checks configuration and provider schema, not a cloud API or plan ([HashiCorp](https://developer.hashicorp.com/terraform/cli/commands/validate)). The audit chain detects accidental local tampering but has no trusted signer or immutable store. The DR test restores a local metadata file; it is not a production recovery exercise.
